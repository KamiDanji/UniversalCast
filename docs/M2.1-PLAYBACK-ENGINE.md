# M2.1 — Playback Engine Abstraction

## Scope

M2.1 extracts a platform-neutral playback contract and implements it with AndroidX Media3. The Android activity sends commands through `PlaybackEngine`; it no longer calls ExoPlayer directly. `load()` prepares without autoplay, matching UCP command separation; the manual **Play URL** UI action explicitly follows load with play.

## Components

- `PlaybackEngine`: platform-neutral command, snapshot, capability, listener and lifecycle contract.
- `PlaybackModels`: UCP-aligned statuses, load request, authoritative snapshot and receiver capabilities.
- `PlaybackStateMapper`: pure mapping from generic media-engine phases to UCP playback statuses.
- `Media3PlaybackEngine`: ExoPlayer implementation, including HTTP(S) validation, load/play/pause/seek/rate/stop, snapshots and player-view attachment.

## State mapping

| Media engine condition | UCP status |
|---|---|
| No media | `idle` |
| Media item present, player idle/preparing | `loading` |
| Buffering | `buffering` |
| Ready before first play | `ready` |
| Actively playing | `playing` |
| Paused after playback was started | `paused` |
| End of media | `ended` |
| Media engine error | `error` |

The engine assigns a generated media ID when one is not supplied; it never uses a bearer media URL as the media ID or title. The engine increments `revision` when an externally relevant state snapshot changes. `snapshot()` samples the current playhead and buffer ahead without requiring a state event. `bufferedMs` is defined here as the buffered duration ahead of the current playhead.

## Baseline capabilities

- Source protocols: progressive HTTP(S), HLS.
- Declared common MIME types: MP4, WebM, MP3, and HLS MIME types.
- Seeking: supported.
- Playback rate: 0.5x–2.0x.
- Audio/subtitle track selection through the UCP adapter: not advertised yet.
- DASH: not advertised.

Declared containers and MIME types do not guarantee every codec; decoding depends on the Android device and installed platform decoders.

## Validation

Unit tests cover all eight UCP statuses and conservative capability reporting. The emulator regression test must repeat the M2.0 HTTP media-host playback scenario and verify play, pause, resume, seek, stop, and the displayed UCP status/revision.

## Explicitly out of scope

M2.1 does not add UCP WebSocket control, mDNS discovery, pairing, authenticated control, or cross-platform serialization. Those remain M2.2–M2.5.
